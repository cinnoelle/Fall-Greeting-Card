# Python Fall Greeting Card 🎃

A Halloween-themed greeting card I made using Python's graphics library. I created a cat-shaped pumpkin using circles and polygons, then added a flickering light effect to its face.

## Features
- Cat-shaped pumpkin drawn using Python graphics
- Flickering animation using loops and timed color changes
- "Happy Fall!" greeting
- Click anywhere to close the window

## Concepts Used
- Python
- Graphics library
- Loops and functions
- Animation using `time.sleep()`
- Mouse input

## How to Run
1. Download the Python file.
2. Make sure you have the `graphics.py` library installed.
3. Run the program in a Python environment that supports graphical windows.
4. Click anywhere in the window after the animation finishes to close it.
